# Audio source drop

Upload the converted Project Strike ZIPs here. The GitHub Action in `.github/workflows/extract-audio.yml` automatically extracts every WAV, preserves the three runtime layers, generates `public/game-assets/audio/audio-manifest.json`, and commits the extracted audio back to the repository.

Recommended names:

- `weapons_player.zip`
- `dlc_weapons.zip`
- `resident.zip`

Do not upload duplicate packs.
