# Source asset workspace

Keep editable/original assets here before runtime compilation.

- `fbx/` — FBX source models/animations
- `blend/` — Blender projects; converted by GitHub Actions
- `gltf/` — multi-file glTF sources
- `textures/` — master PBR textures
- `mocap/` — animation sources
- `originals/` — licensed original archives/reference packages

Do not make the game runtime depend directly on this folder.
