# Environment runtime models

Use realistic, production-ready GLB assets here.

- `buildings/` — warehouses, modular urban structures, interiors
- `modular/` — walls, doors, stairs, floors, catwalks
- `industrial/` — pipes, machinery, electrical, industrial lighting
- `cover/` — barriers, crates, sandbags, barrels, containers
- `foliage/` — optimized trees, bushes, grass
- `terrain/` — rocks, ground meshes and terrain props

Master high-resolution source assets belong under `assets-source/`; runtime files here should be validated GLB/glTF assets.
