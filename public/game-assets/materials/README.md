# Runtime material library

Target categories:

- `concrete/`
- `metal/`
- `rust/`
- `wood/`
- `mud/`
- `dirt/`
- `fabric/`
- `glass/`

Master 4K/8K PBR textures stay in source storage. Runtime material sets should be converted to appropriate mobile/desktop sizes and preferably KTX2. Reusable overlays include rust, scratches, edge wear, mud, wetness, oil/water streaks, soot and grime.
