# Runtime animations

Animation groups:

- `locomotion/`
- `combat/`
- `rifle/`
- `pistol/`
- `shotgun/`
- `sniper/`
- `grenade/`
- `hit_reactions/`
- `deaths/`

Third-person characters use retargetable humanoid clips. First-person weapon clips remain weapon/arms specific. Procedural recoil, ADS alignment, sway, slide tilt, aim offsets and IK are applied at runtime by the animation controller.
